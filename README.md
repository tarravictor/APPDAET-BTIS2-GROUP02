# APPDAET-BTIS2-GROUP2 Kanban Board

A shared kanban board (TO DO / IN PROGRESS / IN REVIEW / DONE) for the BTIS2 Group 2 project. It runs as a static site on GitHub Pages and stores all issues in a free Supabase database, so every member (Victor, Maryloe, Member 3) sees the same live board.

## How it works

```
APPDAET-BTIS2-GROUP2
        │
        ▼
GitHub Pages ────▶ Kanban Board (TO DO / IN PROGRESS / IN REVIEW / DONE)
        │
        ▼
Supabase (online database)  ◀── all members' laptops read/write here
```
